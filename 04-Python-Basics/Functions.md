# Functions

Μέχρι τώρα έχουμε γράψει μικρά προγράμματα χρησιμοποιώντας μεταβλητές, συνθήκες και επαναλήψεις.

Όσο όμως ένα πρόγραμμα μεγαλώνει, ο κώδικας αρχίζει να επαναλαμβάνεται. Οι **Functions (Συναρτήσεις)** μας βοηθούν να οργανώνουμε τον κώδικά μας και να αποφεύγουμε τις επαναλήψεις.

---

#  Τι είναι μια Function;

Μια **Function** είναι ένα κομμάτι κώδικα που εκτελεί μια συγκεκριμένη εργασία.

Αντί να γράφουμε τον ίδιο κώδικα πολλές φορές, τον γράφουμε μία φορά μέσα σε μια συνάρτηση και την καλούμε όποτε τη χρειαζόμαστε.

---

#  Δημιουργία μιας Function

Στην Python χρησιμοποιούμε τη λέξη-κλειδί `def`.

Παράδειγμα:

```python
def welcome():
    print("Welcome to HackTheBasics!")
```

Η συνάρτηση δημιουργήθηκε, αλλά δεν έχει εκτελεστεί ακόμα.

Για να εκτελεστεί, πρέπει να την καλέσουμε.

```python
welcome()
```

Έξοδος:

```text
Welcome to HackTheBasics!
```

---

#  Parameters

Οι Functions μπορούν να δέχονται δεδομένα που ονομάζονται **Parameters**.

Παράδειγμα:

```python
def scan_target(target):
    print("Scanning:", target)

scan_target("192.168.1.10")
```

Έξοδος:

```text
Scanning: 192.168.1.10
```

Μπορούμε να καλέσουμε την ίδια Function όσες φορές θέλουμε.

```python
scan_target("192.168.1.10")
scan_target("192.168.1.20")
scan_target("192.168.1.30")
```

---

#  Return

Μια Function μπορεί επίσης να επιστρέψει μια τιμή χρησιμοποιώντας τη λέξη `return`.

Παράδειγμα:

```python
def get_default_port():
    return 443

port = get_default_port()

print(port)
```

Έξοδος:

```text
443
```

---

#  Παράδειγμα

Ας δημιουργήσουμε μια Function που ελέγχει αν μια θύρα είναι HTTP ή HTTPS.

```python
def check_port(port):

    if port == 80:
        print("HTTP")

    elif port == 443:
        print("HTTPS")

    else:
        print("Unknown")

check_port(80)
check_port(443)
check_port(21)
```

Έξοδος:

```text
HTTP
HTTPS
Unknown
```

Οι Functions χρησιμοποιούνται σχεδόν σε κάθε εργαλείο Cybersecurity.

Χωρίς Functions, ο ίδιος κώδικας θα έπρεπε να γράφεται ξανά και ξανά.
