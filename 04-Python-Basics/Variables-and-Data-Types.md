# Variables & Data Types

Μέχρι τώρα μάθαμε πώς να εκτελούμε ένα πρόγραμμα Python.

Σε αυτό το κεφάλαιο θα μάθουμε πώς η Python αποθηκεύει πληροφορίες χρησιμοποιώντας **Variables (Μεταβλητές)** και **Data Types (Τύπους Δεδομένων)**.

---

#  Τι είναι μια Variable;

Μια **Variable** είναι ένα όνομα που χρησιμοποιούμε για να αποθηκεύσουμε μια τιμή στη μνήμη.

Σκέψου τη σαν ένα "κουτί" μέσα στο οποίο αποθηκεύεις πληροφορίες ώστε να μπορείς να τις χρησιμοποιήσεις αργότερα.

Παράδειγμα:

```python
target_ip = "192.168.1.10"

print(target_ip)
```

Έξοδος:

```text
192.168.1.10
```

Η μεταβλητή `target_ip` αποθηκεύει τη διεύθυνση IP και μπορούμε να τη χρησιμοποιούμε όσες φορές θέλουμε.

---

#  String (str)

Ένα **String** είναι κείμενο.

Γράφεται πάντα μέσα σε εισαγωγικά.

Παράδειγμα:

```python
username = "admin"
password = "password123"

print(username)
print(password)
```

---

#  Integer (int)

Ο τύπος **Integer** χρησιμοποιείται για ακέραιους αριθμούς.

Παράδειγμα:

```python
port = 443

print(port)
```

---

#  Float (float)

Ο τύπος **Float** χρησιμοποιείται για δεκαδικούς αριθμούς.

Παράδειγμα:

```python
version = 3.11

print(version)
```

---

#  Boolean (bool)

Ο τύπος **Boolean** μπορεί να έχει μόνο δύο τιμές:

- True
- False

Παράδειγμα:

```python
is_admin = True
firewall_enabled = False

print(is_admin)
print(firewall_enabled)
```

Τα Boolean χρησιμοποιούνται πολύ συχνά όταν παίρνουμε αποφάσεις μέσα στον κώδικα.

---

#  List

Μια **List** είναι μια συλλογή από πολλές τιμές.

Παράδειγμα:

```python
ports = [22, 80, 443, 8080]

print(ports)
```

Μπορούμε επίσης να προσπελάσουμε συγκεκριμένα στοιχεία:

```python
print(ports[0])
print(ports[2])
```

Έξοδος:

```text
22
443
```

Η αρίθμηση ξεκινά πάντα από το **0**.

---

#  Dictionary

Ένα **Dictionary** αποθηκεύει δεδομένα με μορφή **κλειδί → τιμή (key → value)**.

Παράδειγμα:

```python
target = {
    "ip": "192.168.1.10",
    "port": 80,
    "service": "HTTP"
}
```

Πρόσβαση στις τιμές:

```python
print(target["ip"])
print(target["service"])
```

Έξοδος:

```text
192.168.1.10
HTTP
```

Τα Dictionaries χρησιμοποιούνται πολύ συχνά όταν δουλεύουμε με APIs, JSON και εργαλεία Cybersecurity.

---

#  Αλλαγή τιμής

Οι μεταβλητές μπορούν να αλλάξουν τιμή οποιαδήποτε στιγμή.

```python
port = 80

print(port)

port = 443

print(port)
```

Έξοδος:

```text
80
443
```
