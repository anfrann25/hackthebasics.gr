# Conditions & Loops

Μέχρι τώρα μάθαμε πώς να αποθηκεύουμε δεδομένα σε μεταβλητές.

Σε αυτό το κεφάλαιο θα μάθουμε πώς ένα πρόγραμμα μπορεί να παίρνει αποφάσεις και να εκτελεί τις ίδιες ενέργειες πολλές φορές χωρίς να γράφουμε τον ίδιο κώδικα ξανά και ξανά.

---

# Conditions (Συνθήκες)

Οι συνθήκες επιτρέπουν στο πρόγραμμα να εκτελεί διαφορετικό κώδικα ανάλογα με μια προϋπόθεση.

Στην Python χρησιμοποιούμε κυρίως:

- `if`
- `elif`
- `else`

---

#  Η εντολή if

Η `if` εκτελεί τον κώδικα μόνο αν η συνθήκη είναι αληθής.

Παράδειγμα:

```python
is_admin = True

if is_admin:
    print("Access Granted")
```

Έξοδος:

```text
Access Granted
```

---

#  Η εντολή else

Η `else` εκτελείται όταν η συνθήκη είναι ψευδής.

```python
is_admin = False

if is_admin:
    print("Access Granted")
else:
    print("Access Denied")
```

Έξοδος:

```text
Access Denied
```

---

#  Η εντολή elif

Η `elif` χρησιμοποιείται όταν θέλουμε να ελέγξουμε περισσότερες από μία συνθήκες.

```python
port = 443

if port == 22:
    print("SSH")
elif port == 80:
    print("HTTP")
elif port == 443:
    print("HTTPS")
else:
    print("Unknown Service")
```

---

#  Operators

Οι πιο συνηθισμένοι τελεστές σύγκρισης είναι:

| Operator | Περιγραφή |
|----------|-----------|
| `==` | Ίσο με |
| `!=` | Διαφορετικό από |
| `>` | Μεγαλύτερο από |
| `<` | Μικρότερο από |
| `>=` | Μεγαλύτερο ή ίσο |
| `<=` | Μικρότερο ή ίσο |

Παράδειγμα:

```python
port = 80

if port == 80:
    print("HTTP Detected")
```

---

#  Loops

Τα Loops χρησιμοποιούνται όταν θέλουμε να εκτελέσουμε την ίδια ενέργεια πολλές φορές.

Οι δύο βασικοί τύποι είναι:

- `for`
- `while`

---

#  For Loop

Η `for` χρησιμοποιείται για να διατρέξουμε μια λίστα ή μια ακολουθία δεδομένων.

```python
ports = [22, 80, 443]

for port in ports:
    print(port)
```

Έξοδος:

```text
22
80
443
```

---

Μπορούμε επίσης να διατρέξουμε λίστες με IP Addresses.

```python
targets = [
    "192.168.1.10",
    "192.168.1.20",
    "192.168.1.30"
]

for target in targets:
    print("Scanning", target)
```

---

#  While Loop

Η `while` εκτελείται όσο μια συνθήκη παραμένει αληθής.

```python
counter = 1

while counter <= 5:
    print(counter)
    counter += 1
```

Έξοδος:

```text
1
2
3
4
5
```

---

#  Infinite Loops

Αν η συνθήκη μιας `while` δεν γίνει ποτέ False, τότε το πρόγραμμα θα εκτελείται για πάντα.

Παράδειγμα:

```python
while True:
    print("Running...")
```

Προσοχή! Αυτό δημιουργεί ένα **Infinite Loop** και το πρόγραμμα δεν θα σταματήσει μόνο του.
