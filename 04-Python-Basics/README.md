# Python Basics

Η **Python** είναι μία από τις πιο δημοφιλείς γλώσσες προγραμματισμού και αποτελεί βασικό εργαλείο για πολλούς επαγγελματίες του Cybersecurity.

Σε αντίθεση με άλλα κεφάλαια, εδώ δεν θα μάθουμε ολόκληρη τη γλώσσα. Στόχος μας είναι να αποκτήσουμε τις βασικές γνώσεις που χρειάζονται για να κατανοούμε, να τροποποιούμε και να δημιουργούμε απλά Python scripts.

---

# 🛡️ Γιατί η Python στο Cybersecurity;

Η Python χρησιμοποιείται σχεδόν σε κάθε τομέα του Cybersecurity.

Με αυτήν μπορούμε να:

- Αυτοματοποιούμε επαναλαμβανόμενες εργασίες.
- Αναλύουμε αρχεία και logs.
- Επικοινωνούμε με δίκτυα και υπηρεσίες.
- Δημιουργούμε μικρά εργαλεία.
- Κατανοούμε υπάρχοντα scripts και exploits.
- Συμμετέχουμε σε CTF Challenges.

Δεν χρειάζεται να είσαι προγραμματιστής για να ασχοληθείς με το Cybersecurity, όμως η γνώση της Python θα σου λύσει τα χέρια σε πάρα πολλές περιπτώσεις.

---

# 📚 Σε αυτό το κεφάλαιο

Σε αυτή την ενότητα θα μάθεις:

- Τι είναι η Python και πώς εγκαθίσταται.
- Τι είναι οι μεταβλητές και οι τύποι δεδομένων.
- Πώς λειτουργούν οι συνθήκες (`if`, `else`).
- Πώς χρησιμοποιούνται οι επαναλήψεις (`for`, `while`).
- Πώς δημιουργούμε συναρτήσεις (`functions`).
- Πώς διαβάζουμε και γράφουμε αρχεία.
- Πώς να δημιουργήσεις το πρώτο σου μικρό εργαλείο σε Python.
